F-Droid перестал публиковать APK клиента на GitHub. Этот репозиторий помогает оставить ещё одну дверь открытой.

Я учусь в средней школе в Китае и хочу сказать честно: мои технические навыки пока ограничены. Я не могу вносить изменения в код F-Droid или добавлять новые функции, и многое в мире свободного ПО мне пока не по силам. Но мне очень близко то, что означает открытый исходный код: программы могут быть свободными и прозрачными, а незнакомые люди могут помогать друг другу и создавать их вместе просто потому, что так правильно. Эта идея вдохновила меня внести свой вклад, пусть даже небольшой.

Вот что я могу сделать: F-Droid находится на GitLab и больше не публикует новые версии на GitHub. Когда официальный сайт или GitLab недоступны — а там, где я живу, такое случается часто, — людям негде взять последнюю версию клиента. Если даже установить магазин не получается, нельзя познакомиться и с тысячами приложений FOSS в нём. Мне это кажется неправильным, особенно по отношению к таким людям, как я: школьникам, любознательным детям и всем, кто только начинает учиться. Поэтому я создал этот репозиторий. Я зеркалирую здесь каждый новый официальный релиз клиента F-Droid для Android именно в том виде, в каком F-Droid его собирает и подписывает: без изменений и перепаковки — всегда. Считайте это дополнительной дверью: ещё одним местом, где можно получить клиент, если через главный вход пройти не удаётся.

## Что входит в каждый релиз

При каждом выходе новой официальной версии клиента я загружаю **два основных файла — каждый раз без исключений**, а рядом храню официальный ключ для тех, кто хочет провести более глубокую проверку:

- `F-Droid_<version>.apk` — официальный клиент без изменений
- `F-Droid_<version>.apk.sha256.txt` — обычный текстовый файл с **хешем файла** соответствующего APK
- `f-droid.org-signing-key.gpg` — официальный открытый ключ GPG для расширенной проверки цепочки публикации (см. ниже)

`.sha256.txt` — это обычный текстовый файл. Откройте его на любом телефоне, и вы увидите одну строку: SHA-256 этой сборки. Я намеренно оставляю расширение `.txt` — без хитростей с его удалением, — чтобы файл открывался на любом устройстве и был понятен начинающим.

## О файле `.sha256.txt` (пожалуйста, прочитайте)

**Хеш внутри `.txt` — это хеш самого APK-файла. Это НЕ отпечаток сертификата подписи. Это совершенно разные вещи.**

- Каждая сборка APK отличается, поэтому **хеш этого файла меняется с каждой версией.** Это нормально: новая версия — новый хеш.
- Он подтверждает только то, что файл не повредился при загрузке. **Он не подтверждает, кто подписал пакет.**
- Чтобы убедиться, что это действительно официальный пакет F-Droid, отдельно проверьте сертификат (см. следующий раздел).

Быстрая проверка на большинстве компьютеров:

```sh
sha256sum -c F-Droid_*.apk.sha256.txt
```

На телефоне нет `sha256sum`? Просто откройте `.txt` и сравните указанный там хеш со значением на странице релиза. Если они совпадают, файл загружен без повреждений.

## Проверьте и подпись (не пропускайте этот шаг)

Здесь три уровня проверки. Для обычной установки достаточно первых двух. Третий — запасной ключ для тех, кто любит проверять всё особенно тщательно.

| | Хеш файла (из `.txt`) | Отпечаток сертификата (**главное для Android**) | Открытый ключ GPG (расширенная проверка цепочки релиза) |
|---|---|---|---|
| Что подтверждает | Файл не повреждён при загрузке | Пакет действительно выпущен F-Droid | Официальная цепочка публикации не была подменена |
| Меняется ли | **С каждой версией** | **Никогда** (действителен до 2037 года) | **Отпечаток остаётся прежним** (действителен до 2037 года; продление не меняет ключ) |
| Как проверить | `sha256sum -c` или визуально | `keytool -printcert -jarfile` | `gpg --verify` (нужен файл `.asc`) |
| Важность в повседневном использовании | Полезно | ⭐ **Главное — проверяйте при каждой установке** | По желанию, на компьютере |

**Отпечаток сертификата Android**, который нужно искать, **всегда** один и тот же — его Android проверяет при установке и обновлении:

```
43238d512c1e5eb2d6569f4a3afbf5523418b82e0a3ed1552770abb9a9c9ccab
```

(F-Droid указывает, что этот долгосрочный сертификат подписи действителен до 2037 года.)

- **Хеш APK не совпадает?** Это нормально: у каждого релиза свой хеш.
- **Сертификат не совпадает?** Остановитесь. **Не устанавливайте приложение** — даже если имя файла выглядит правильным, а хеш кажется «красивым».
- В Linux / macOS выполните эту команду:

  ```sh
  keytool -printcert -jarfile F-Droid_*.apk
  ```

  Она должна вывести тот же отпечаток сертификата. Android также отклонит любое последующее обновление с несовпадающей подписью, поэтому правильная **самая первая установка** обеспечит безопасность всех дальнейших обновлений.

### Для продвинутых: подпись релиза GPG (необязательно, но полезно знать)

Файл `f-droid.org-signing-key.gpg` в этом репозитории содержит официальный открытый ключ. Это **не тот же ключ, что сертификат подписи Android** выше: это два отдельных ключа, не путайте их.

- **Сертификат Android** (средний столбец выше): его проверяет Android при установке. Он защищает от подмены. До 2037 года его отпечаток всегда `43238d…ccab`.
- **Открытый ключ GPG** (этот раздел): нужен для проверки на компьютере. С его помощью проверяется официальный файл подписи `.asc`, расположенный рядом с APK, и подтверждается, что пакет прошёл через собственную цепочку публикации F-Droid.

**Как использовать файл `.gpg`:**

1. Импортируйте ключ один раз:

   ```sh
   gpg --import f-droid.org-signing-key.gpg
   ```

   Ниже указан отпечаток официального основного ключа — сверьте его при импорте:

   ```
   37D2 C987 89D8 3119 4839  4E3E 41E7 044E 1DBA 2E89
   ```

   Тот же отпечаток означает, что это тот же ключ, просто продлённый.

2. Проверьте подпись релиза (для этого нужен официальный файл `.asc`, расположенный рядом с APK):

   ```sh
   gpg --verify F-Droid_<version>.apk.asc F-Droid_<version>.apk
   ```

   Сообщение `Good signature from "F-Droid ..."` означает, что цепочка публикации не нарушена.

**⏳ Важное замечание об истечении срока в 2037 году:**

Этот ключ GPG действителен до **2037 года**. После этого проверка может вывести `key expired`. Это **обычное истечение срока, а не подмена**: официальная команда продлевает срок действия ключа, и неизменившийся отпечаток означает, что это тот же ключ.

> Для повседневной установки на телефон достаточно **отпечатка сертификата Android** выше и совпадающего `.sha256.txt` — это уже надёжная защита. GPG — дополнительная мера на всякий случай. Ключ уже здесь и будет доступен, когда он понадобится.
