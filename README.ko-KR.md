F-Droid는 GitHub에서 클라이언트 APK 배포를 중단했습니다. 이 저장소는 그 문을 계속 열어 두기 위해 만들어졌습니다.

저는 중국의 중학생이고, 솔직히 말씀드리고 싶습니다. 제 기술은 아직 부족합니다. F-Droid의 코드를 수정하거나 기능을 추가할 수 없고, 자유 소프트웨어 세계에는 아직 제 힘으로 이해하기 어려운 것들이 많습니다. 하지만 오픈 소스가 의미하는 바를 정말 좋아합니다. 소프트웨어는 자유롭고 투명할 수 있으며, 서로 모르는 사람들이 단지 그것이 옳은 일이라는 이유만으로 서로 돕고 함께 만들어 갈 수 있다는 생각입니다. 그 생각에 감동해, 작게나마 무언가를 돌려주고 싶었습니다.

제가 할 수 있는 일은 이렇습니다. F-Droid의 본거지는 GitLab이며, 이제 GitHub에는 새 버전을 배포하지 않습니다. 제가 있는 곳에서는 자주 일어나는 일이지만, 공식 사이트나 GitLab에 접속할 수 없으면 사람들은 최신 클라이언트를 구할 방법이 없습니다. 스토어조차 설치할 수 없다면 그 안에 있는 수천 개의 FOSS 앱을 만날 수도 없습니다. 특히 저와 같은 학생, 호기심 많은 아이들, 이제 막 배우기 시작한 사람들에게는 이런 상황이 잘못된 것처럼 느껴졌습니다. 그래서 이 저장소를 만들었습니다. F-Droid가 빌드하고 서명한 공식 Android 클라이언트를 새 버전이 나올 때마다 그대로 미러링합니다. 수정도 재패키징도 절대 하지 않습니다. 정문으로 들어갈 수 없는 사람들을 위한 또 하나의 문이라고 생각해 주세요.

## 각 릴리스에 포함되는 파일

공식 클라이언트의 새 버전이 나올 때마다 **핵심 파일 두 개를 매번 빠짐없이** 업로드합니다. 더 자세히 검증하고 싶은 분들을 위해 공식 키도 함께 보관합니다.

- `F-Droid_<version>.apk` — 수정되지 않은 공식 클라이언트
- `F-Droid_<version>.apk.sha256.txt` — 해당 APK의 **파일 해시**가 들어 있는 일반 텍스트 파일
- `f-droid.org-signing-key.gpg` — 릴리스 체인을 고급 검증하기 위한 공식 GPG 공개 키(아래 참조)

`.sha256.txt`는 단순한 텍스트 파일입니다. 어떤 휴대전화에서든 열면 이 빌드의 SHA-256 값이 한 줄로 표시됩니다. 일부러 `.txt` 확장자를 유지합니다. 확장자를 없애는 식의 꼼수를 쓰지 않아 어떤 기기에서든 열 수 있고 초보자도 읽을 수 있습니다.

## `.sha256.txt` 파일에 대해 (꼭 읽어 주세요)

**`.txt` 안의 해시는 APK 파일 자체의 해시입니다. 서명 인증서의 지문이 아닙니다. 둘은 완전히 다른 것입니다.**

- APK 빌드는 버전마다 다르므로 **이 파일 해시는 버전이 바뀔 때마다 달라집니다.** 새 버전이면 새 해시인 것이 정상입니다.
- 다운로드 중 파일이 손상되지 않았다는 것만 증명합니다. **패키지에 누가 서명했는지는 증명하지 않습니다.**
- 실제로 F-Droid의 공식 패키지인지 확인하려면 인증서를 별도로 검증해야 합니다(다음 섹션 참조).

대부분의 컴퓨터에서 빠르게 확인하려면 다음 명령을 실행하세요.

```sh
sha256sum -c F-Droid_*.apk.sha256.txt
```

휴대전화에 `sha256sum`이 없나요? `.txt`를 열어 안에 적힌 해시와 릴리스 페이지에 표시된 값을 비교하면 됩니다. 두 값이 일치하면 다운로드한 파일은 온전합니다.

## 서명도 확인하세요 (건너뛰지 마세요)

검증 방법은 세 단계입니다. 일상적인 설치에는 앞의 두 단계면 충분합니다. 세 번째는 꼼꼼히 확인하고 싶은 분들을 위한 예비 열쇠입니다.

| | 파일 해시 (`.txt`) | 인증서 지문 (**Android의 핵심**) | GPG 공개 키 (고급 릴리스 체인 검증) |
|---|---|---|---|
| 증명하는 내용 | 다운로드한 파일이 손상되지 않았음 | 패키지가 실제로 F-Droid에서 나온 것임 | 공식 릴리스 체인이 변조되지 않았음 |
| 변경 여부 | **버전마다 변경** | **변경되지 않음** (2037년까지 유효) | **지문은 동일** (2037년까지 유효하며 갱신해도 같은 키) |
| 확인 방법 | `sha256sum -c` 또는 직접 비교 | `keytool -printcert -jarfile` | `gpg --verify` (`.asc` 파일 필요) |
| 일상적인 우선순위 | 유용함 | ⭐ **가장 중요 — 설치할 때마다 확인하세요** | 선택 사항, 컴퓨터에서 확인 |

확인해야 할 **Android 인증서 지문**은 **항상** 다음 값입니다. Android는 설치 및 업데이트 시 이 값을 확인합니다.

```
43238d512c1e5eb2d6569f4a3afbf5523418b82e0a3ed1552770abb9a9c9ccab
```

(F-Droid가 공개한 장기 서명 인증서이며, 유효 기간은 2037년까지입니다.)

- **APK 해시가 일치하지 않나요?** 정상입니다. 릴리스마다 해시가 다릅니다.
- **인증서가 일치하지 않나요?** 중단하세요. 파일 이름이 그럴듯하거나 해시가 아무리 “예뻐” 보여도 **설치하지 마세요**.
- Linux / macOS에서는 다음 명령을 실행하세요.

  ```sh
  keytool -printcert -jarfile F-Droid_*.apk
  ```

  동일한 인증서 값이 출력되어야 합니다. Android는 서명이 일치하지 않는 이후 업데이트도 거부하므로, **최초 설치**를 올바르게 하면 이후 업데이트도 안전하게 받을 수 있습니다.

### 고급: GPG 릴리스 서명 (선택 사항이지만 알아 두면 좋습니다)

이 저장소에 포함된 `f-droid.org-signing-key.gpg`는 공식 공개 키입니다. 위의 **Android 서명 인증서와는 다른 키**입니다. 서로 별개의 키이므로 혼동하지 마세요.

- **Android 인증서** (위 표의 가운데 열): 설치할 때 Android가 확인하는 인증서입니다. 사칭을 방지합니다. 2037년까지 지문은 항상 `43238d…ccab`입니다.
- **GPG 공개 키** (이 섹션): 컴퓨터에서 검증할 때 사용합니다. APK 옆에 있는 공식 `.asc` 서명 파일을 확인하여 패키지가 F-Droid 자체 릴리스 체인에서 나온 것임을 증명합니다.

**`.gpg` 파일 사용 방법:**

1. 키를 한 번 가져옵니다.

   ```sh
   gpg --import f-droid.org-signing-key.gpg
   ```

   공식 기본 키의 지문은 다음과 같습니다. 가져올 때 비교하세요.

   ```
   37D2 C987 89D8 3119 4839  4E3E 41E7 044E 1DBA 2E89
   ```

   지문이 같으면 같은 키입니다. 갱신만 된 것입니다.

2. 릴리스 서명을 확인합니다(APK 옆에 있는 공식 `.asc` 파일이 필요합니다).

   ```sh
   gpg --verify F-Droid_<version>.apk.asc F-Droid_<version>.apk
   ```

   `Good signature from "F-Droid ..."`라고 표시되면 릴리스 체인이 온전하다는 뜻입니다.

**⏳ 2037년 만료 관련 안내:**

이 GPG 키는 **2037년**까지 유효합니다. 그 이후에는 확인 결과에 `key expired`가 표시될 수 있습니다. 이는 **변조가 아니라 정상적인 만료**입니다. 공식 팀이 키를 갱신하며, 지문이 그대로라면 같은 키입니다.

> 일상적인 휴대전화 설치에는 위의 **Android 인증서 지문**과 일치하는 `.sha256.txt`만 있으면 충분합니다. 그것만으로도 매우 안전합니다. GPG는 추가 안전장치입니다. 키는 이미 여기에 있으니 필요할 때 사용하면 됩니다.
